# GANDAL SDK 0.5.0

Publication du client de la cellule IAM, aligné sur le contrat
`iam/contracts/openapi-iam.yaml` v1.7.0.

## Ce qui change pour l'appelant

```python
from gandal_sdk import GandalClient
from gandal_sdk.cells.iam import DemandeDecision, DemandeRessource

client = GandalClient.from_env()  # lit GANDAL_IAM_* ou le profil credentials
decision = client.iam.decide(
    DemandeDecision(
        action="vm:create",
        ressource=DemandeRessource(type="vm", projet="prj_01"),
    )
)
```

Sans `iam_endpoint`, `client.iam.*` lève `CellUnavailable` comme avant.

## Couverture

| Famille | Routes | Helpers |
| --- | --- | --- |
| A OIDC / JWKS | discovery, certs | `openid_configuration`, `jwks` |
| B Décisions | decide, batch, actions | `decide`, `decide_batch`, `list_actions` |
| C Sujets / audit | subjects, roles, audit | `list_subjects`, `get_me`, `set_subject_roles`, `list_audit`… |
| D Projets / accès | projects, members, access-requests | `create_project`, `invite_member`, `request_access`… |
| E Quotas | quotas, reservations, capacity | `reserve_quota`, `commit_reservation`, `publish_quota_capacity`… |
| F Machines / STS / politiques | keys, assume-role, policies | `create_access_key`, `assume_role`, `create_policy`… |
| G Ressources / tags | grants, tags | `grant_resource_right`, `set_tags`… |

## Identifiants

```ini
[default]
endpoint = http://localhost:8000
iam_endpoint = https://10.30.0.30:8081/v1
iam_token = ...
iam_ca = ~/.gandal/gandal-ca.crt
```

Variables : `GANDAL_IAM_ENDPOINT`, `GANDAL_IAM_TOKEN`, `GANDAL_IAM_CA`.

## Erreurs

Les réponses `application/problem+json` (type, title, detail, correlation_id)
sont mappées en `GandalApiError` ; le `code` est le dernier segment de `type`.

## Migration depuis le stub

Remplacer les appels inventés du stub (`login`, `get_rights`…) par les
méthodes du contrat. L'authentification humaine reste OIDC (Keycloak) ;
le SDK porte le Bearer obtenu ailleurs via `cell_tokens["iam"]` ou
`set_iam_token`.
