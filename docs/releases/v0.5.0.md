# GANDAL SDK v0.5.0

**Date :** 2026-11-04 · **Version précédente :** v0.4.0 · **Type :** mineure, avec changements incompatibles (version 0.x)

## Résumé

Cette version branche `client.iam` sur le contrat IAM 1.7.0 (decision-service +
OIDC) : 70 routes couvertes, familles A à G. Les apps externes peuvent demander
des décisions d'autorisation, gérer sujets / projets / quotas / politiques /
clés machine, sans réinventer le HTTP ni parser `problem+json` à la main.
L'hyperviseur 0.4.0 reste inchangé.

## Changements incompatibles et migration

| Changement | Avant | Après | Action requise |
| --- | --- | --- | --- |
| API `IamCell` | stub (`login`, `validate_token`, `get_rights`…) levant `CellUnavailable` | API alignée sur le contrat (`decide`, `get_me`, `reserve_quota`…) | remplacer les appels inventés du stub par les helpers du contrat |
| Endpoint IAM | ignoré | requis via `cell_urls` / `cell_tokens` / `cell_verify` ou `from_env()` | configurer `GANDAL_IAM_ENDPOINT`, `GANDAL_IAM_TOKEN`, optionnellement `GANDAL_IAM_CA` |

Sans endpoint IAM, les appels lèvent toujours `CellUnavailable`.

## Nouveautés

**Cellule IAM.** Décisions (simple et batch), sujets et rôles, projets et
membres, demandes d'accès, quotas / réservations / capacité, machines, clés,
STS, politiques, ressources, tags, discovery OIDC et JWKS.

```python
from gandal_sdk import GandalClient
from gandal_sdk.cells.iam import DemandeDecision, DemandeRessource

client = GandalClient.from_env()  # iam_endpoint / iam_token / iam_ca
decision = client.iam.decide(
    DemandeDecision(
        action="vm:create",
        ressource=DemandeRessource(type="vm", projet="prj_01"),
        contexte={"ram_gb": 2},
    )
)
reservation = client.iam.reserve_quota(ressources={"vm_count": 1}, projet="prj_01")
```

**Identifiants cellule.** `GANDAL_IAM_ENDPOINT` / `GANDAL_IAM_TOKEN` /
`GANDAL_IAM_CA` ; clés de profil `iam_endpoint` / `iam_token` / `iam_ca` ;
paramètre `cell_verify` pour le fichier CA TLS.

**Transport.** Les réponses `application/problem+json` (RFC 9457) sont mappées
en `GandalApiError` (code = dernier segment de `type`).

**Contrats.** Instantané `openapi/gandal-iam.json` ;
`scripts/sync_openapi.py --service gandal-iam --yaml …`.
