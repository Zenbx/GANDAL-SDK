# GANDAL SDK v0.4.0

**Date :** 2026-11-02 · **Version précédente :** v0.3.0 · **Type :** mineure, avec changements incompatibles (version 0.x)

## Résumé

Cette version branche `client.hypervisor` sur la cellule
[gandal-hypervisor](https://github.com/BalaAndegue/gandal-hypervisor) et le
valide **contre le pool XCP-ng réel** (rem / jade / emilia), en bac à sable
`sdk-it-*`. Les apps externes peuvent créer, alimenter, redimensionner et
supprimer des VM du pool via le SDK, sans jamais parler XAPI ni détenir le
mot de passe root.

## Changements incompatibles et migration

| Changement | Avant | Après | Action requise |
| --- | --- | --- | --- |
| `HypervisorCell.create_vm` | levait `CellUnavailable` ; signature promise `VmRef` | renvoie `CreatedVm` (VM + opération) | `created = client.hypervisor.create_vm(...)` puis `wait_for_operation(created.operation)` |
| `update_vm` / `power` / `delete_vm` | `CellUnavailable` | renvoient `CellOperation` | attendre avec `wait_for_operation` |
| Endpoint cellule | ignoré | requis via `cell_urls` / `cell_tokens` ou `from_env()` | configurer `GANDAL_HYPERVISOR_ENDPOINT` et `GANDAL_HYPERVISOR_TOKEN` |

## Nouveautés

**Cellule hyperviseur.** Création, modification, alimentation, suppression,
`health()`, opérations asynchrones et waiters
(`wait_until_running` / `stopped` / `deleted`, `wait_for_operation`).

```python
from gandal_sdk import GandalClient
from gandal_sdk.cells.hypervisor import PowerAction, VmSpec

client = GandalClient.from_env()  # avec hypervisor_endpoint / hypervisor_token
created = client.hypervisor.create_vm(
    VmSpec(name="sdk-it-web", ram_gb=1, vcpu=1, vram_gb=0, ssd_gb=25)
)
client.hypervisor.wait_for_operation(created.operation)
vm = client.hypervisor.wait_until_running(created.vm)
```

**Identifiants cellule.** `GandalClient(cell_urls=…, cell_tokens=…)` ;
`from_env()` lit `GANDAL_HYPERVISOR_ENDPOINT` / `GANDAL_HYPERVISOR_TOKEN`
et les clés de profil `hypervisor_endpoint` / `hypervisor_token`.

**Contrats et scripts.** Instantané `openapi/gandal-hypervisor.json`,
`scripts/run_hypervisor_integration.sh`, équivalent Windows
`scripts/run_hypervisor_integration.ps1`, variable `GANDAL_IT_SSD_GB` pour
aligner les tests sur la taille réelle du disque modèle.

## Limites connues

- Autres cellules (IAM, réseau, stockage, DNS, notifications) encore en stub.
- Console VM : non exposée (relais authentifié requis).
- Bac à sable par défaut côté cellule (`sdk-it-*`, 1 vCPU, 1 Go, 2 VM).
- Règle R1 (démarrer sur l'hôte du disque système) pas encore appliquée à la création.
- CI SDK contre la cellule privée pas encore branchée.
