# GANDAL SDK v0.7.0

**Date :** 2026-11-21 · **Version précédente :** v0.6.0 · **Type :** mineure, avec changements incompatibles (version 0.x)

## Résumé

Cette version branche `client.network` sur **agent_reseau** (executions `/v1`,
modes check/apply) et livre la documentation MkDocs du SDK, avec un README
séparé pour l'installation utilisateur et le développement.

## Changements incompatibles et migration

| Changement | Avant | Après | Action requise |
| --- | --- | --- | --- |
| `NetworkCell.create_network` / helpers | stub `(project_id, name)` → `CellUnavailable` | `target_id`, `resource_key`, `mode` check\|apply, corps agent | réécrire les appels ; toujours `check` puis `apply` |
| `detach_vm_from_project` | stub `CellUnavailable` | `GandalError` (pas d'opération unique ACL/EVPN) | appeler `detach_vm` (`vm-networks`/remove) ou `user_vms` selon l'architecture |

Sans migration, tout code qui attendait encore le stub réseau ou
`detach_vm_from_project` comme no-op lève désormais une erreur métier.

## Nouveautés

**Cellule réseau.** `client.network` parle à l'agent (`gandal_agent`) :
`health`, `run`, `get_execution`, `submit`, helpers alignés NetworkPort
(`create_network`, `rename_network`, `delete_network`, `attach_vm`,
`detach_vm`) et raccourcis `user_vms` / `vm_acl` / `flows` / `xcpng`.

```python
from gandal_sdk import GandalClient
from gandal_sdk.cells.network import NetworkMode

client = GandalClient.from_env()  # GANDAL_NETWORK_ENDPOINT / TOKEN
plan = client.network.create_network(
    target_id="cluster-lab",
    resource_key="request-a",
    name="Projet A",
    mode=NetworkMode.CHECK,
)
client.network.require_succeeded(plan)
```

**Credentials.** `GANDAL_NETWORK_ENDPOINT`, `GANDAL_NETWORK_TOKEN`,
clés `network_endpoint` / `network_token` dans `~/.gandal/credentials`,
et `client.set_network_token(...)`.

**Documentation.** Site MkDocs (guides, référence, recettes), guide réseau,
README install utilisateur vs développement, CI OpenAPI / Alembic stabilisée.

## Limites connues

- Cellules stockage, DNS, notifications encore en stub (`CellUnavailable`).
- `detach_vm_from_project` n'a pas d'équivalent unique côté agent.
- Cinq helpers `storages` pointent encore vers des routes retirées du backend.
- Pas de script d'intégration live IAM ni signeur SSH.
- `GardeIam` / `AccesSsh` ne remplacent pas le contrôle d'accès serveur.
